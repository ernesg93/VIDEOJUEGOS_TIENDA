# PRD — Tienda de Videojuegos

## Visión

Construir una tienda web en Django que sirva como proyecto de aprendizaje incremental: entender fundamentos, aplicar buenas prácticas y evolucionar funcionalidades sin perder claridad.

## Estado real actual

Hoy el proyecto ya tiene:

- Home y contacto
- Catálogo con listado y detalle por slug
- Buscador por texto libre
- Módulo de usuarios (login, logout, perfil, registro)

Referencia factual detallada: `docs/project-state.md`.

## Roadmap de aprendizaje

### Fase A — Fundamentos (prioridad máxima)
- Dominar apps, urls, templates, settings y ciclo request/response.

### Fase B — Calidad de autenticación y UX de usuarios
- Fortalecer tests de usuarios y mensajes de error.

### Fase C — Evolución de catálogo y buscador
- Mejorar modelo de productos, filtros y experiencia de navegación.

### Fase D — Features de negocio futuras
- Carrito, checkout y pagos (cuando bases estén sólidas).

## Principios de priorización

1. Fundamentos antes que expansión rápida de features.
2. Cada cambio debe dejar evidencia en código/tests/docs.
3. El roadmap no contradice funcionalidades ya implementadas.
